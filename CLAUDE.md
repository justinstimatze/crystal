# Notes for coding agents

Before running any `crystal team-solve` experiment, read `bench/teamsolve/RUNBOOK.md`: it lists the
measurement traps (silent provider caps, reasoning flags, grading under load), host rate limits,
cloud-session memory and time limits, and how to use Modal from a cloud session. Results and
pre-registered bars are in `docs/TEAMSOLVE_FINDINGS.md`; the literature behind the design is in
`docs/GARDEN_LITREVIEW.md`.
